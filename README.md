# EvaluaDoc

EvaluaDoc ayuda a docentes a organizar bancos de preguntas y preparar evaluaciones imprimibles.

## Descargar

[Descargar la última versión de EvaluaDoc](https://github.com/pab-crypto/evaluadoc-actualizaciones/releases/latest)

En la página del lanzamiento, descarga el archivo **EvaluaDoc-Setup-...exe** para instalar el programa en Windows. Los demás archivos son auxiliares y no necesitas descargarlos para instalarlo.

## Funciones principales

- Organizar preguntas por asignatura, tema y dificultad.
- Crear ejercicios de selección múltiple, completar o ambos.
- Configurar puntajes y generar distintas filas del examen.
- Asignar evaluaciones a estudiantes y preparar el examen y su clave de respuestas.

Las nuevas versiones se publicarán en este repositorio. Cuando haya una actualización compatible, EvaluaDoc podrá avisarte desde la aplicación.
